# Frontend Sneaker Store

This is a frontend-only e-commerce sneaker website built to practice clean UI design and basic frontend logic.

## Features
- Modern sneaker store user interface  
- Product slider with multiple categories  
- Dynamic product change using JavaScript  
- Color and size selection  
- Buy now popup (UI only)  
- Fully responsive design  

## Technologies Used
- HTML  
- CSS  
- JavaScript  

## Project Structure

├── index.html
├── style.css
├── app.js
├── img/
│   ├── product images and icons

## Preview
Open the `index.html` file in your browser to view the project.

## Purpose
This project was created to improve frontend development skills including layout design, DOM manipulation, and responsive UI.

## Note
This is a frontend-only project. No backend or real payment functionality is implemented.
